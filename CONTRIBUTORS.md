## How to Get Listed

Contributions of any kind are welcome and will be recognized here! This includes:

- 💻 Code contributions (features, bug fixes, refactoring)
- 📖 Documentation improvements
- 🐛 Bug reports with detailed information
- 💡 Feature suggestions and design discussions
- 🌐 Translations
- 🎨 Design and UX improvements
- 📢 Promotion and community building
- 🧪 Testing and quality assurance

To be added to this list:

1. Make a contribution (code, docs, bug report, etc.)
2. Your name will be added in the next release
3. Or submit a PR updating this file yourself!

Paperlint draws inspiration from:

- **markdownlint** - Configuration and rule design patterns
- **ESLint** - Pluggable architecture and severity levels
- **Clippy** - Rust-first linting philosophy
- **Chinese academic writing guides** - Rule definitions and conventions
